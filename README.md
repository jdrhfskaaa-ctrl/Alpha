# グラビティークイズ

一人称・重力吸着パズル。巨大な物体（アルファベット／画像／図形）の表面を歩き回り、
「乗っているせいで全体が見えない」状態から、地表の探索だけで正体を当てる／組み立てるゲーム。

**▶ プレイ: https://jdrhfskaaa-ctrl.github.io/Alpha/**

React Three Fiber + Three.js + three-mesh-bvh 製。物理エンジンを使わず、
毎フレーム最近接面へ吸着することで「どの面の上でも歩ける」重力を実現している。

## モード

- **アルファベット**: 巨大な文字の上を歩き、何の文字かを当てる。サイズ3段階。
- **画像**: 手持ちの画像4枚以上を土台にし、今どの画像の上にいるかを4択で当てる。
- **図形**: バラバラのピース上でスタート。クリックでワープ、面と面を繋いでお題の図形を組み立てる。
  - イージー（合同ピース・自由に組める）／ハード（固有ピース・組み方は厳密）／ランダム。
- **エンドレス**（アルファベット・図形）: 制限時間内に解き続け、クリア数を競う。

## 特徴

- タイトルロゴはカタカナ1文字ずつを多角形ピースで構成し、読み込み時に組み上がる
- 部門別ランキング（ローカル保存・表彰台表示）
- Web Audio による効果音・環境音（音声ファイル不要）
- 正解演出（ドリーアウトカメラ＋祝祭パーティクル）、接続パーティクル
- 探索トレイル（M キーで表示切替）
- 設定（FOV・感度・上下反転・酔い対策の再配向スムージング・音量）

## 操作

W/A/S/D 移動 ／ マウス 視点 ／ Shift ダッシュ ／ Enter 回答 ／ R リスポーン ／ M 足跡
図形モード: クリック ワープ ／ F 見ている面をマーク→接続 ／ X マーク解除

## 開発

```bash
npm install
npm run dev            # 開発サーバ
npm run build          # 本番ビルド（dist/）— GitHub Pages はこれを自動デプロイ
npm run build:single   # 単一HTMLを生成
npm run lint
```

## デプロイ

`main` ブランチへの push で GitHub Actions が `npm run build` を実行し、
`dist/` を GitHub Pages に自動公開する（`.github/workflows/deploy.yml`）。

初回のみ GitHub の **Settings → Pages → Source** を **「GitHub Actions」** に設定する。
